◎ MY LIBRARY — SAVED IN /roms/

How to add games so they stay saved (GitHub Pages):

1. Dump your own cartridge you own (GBxCart, Retrode, etc.)
2. Put ROM file in /roms/ folder — e.g. roms/My Game.gba
3. (Optional) Put cover in /roms/covers/ — e.g. roms/covers/My Game.jpg
4. Edit /roms/manifest.json and add entry:
{ "id": "my-game", "name": "My Game", "file": "roms/My Game.gba", "cover": "roms/covers/My Game.jpg", "ext": "gba", "core": "gba", "size": 16777216, "added": 1725060000000 } 5. git add roms/ && git commit -m "add game" && git push
Your .io site rebuilds and game appears. No server needed — everything is static files in the repo.
